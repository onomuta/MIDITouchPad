# MIDITouchPad

**日本語** | [English](README.en.md)

Mac のトラックパッドに触れた位置を MIDI CC として送信するメニューバー常駐アプリ。

<img src="docs/screenshot.png" alt="MIDITouchPad のメニューバーパネル" width="320">

## ダウンロード

[Releases](https://github.com/onomuta/MIDITouchPad/releases/latest) から最新の `MIDITouchPad-x.y.z.zip` を
ダウンロードして展開し、`MIDITouchPad.app` を `/Applications` に移す。Developer ID で署名され、
Apple の公証を受けているので、Gatekeeper の警告なしに開ける。macOS 13 以降が必要。

## 送信内容

| 対象 | 既定値 | 備考 |
| --- | --- | --- |
| X 座標 | CC 1 | 左 0 → 右 127 |
| Y 座標 | CC 2 | 手前 0 → 奥 127（反転可） |
| タッチ有無 | CC 64（基準 CC） | 接触中 127 / 離すと 0。数字キーで CC 番号を切り替えられる |

チャンネル・CC 番号・Y 反転・14bit 解像度・離したときに値を保持するかはメニューから変更でき、
`UserDefaults` に保存される。

出力先は自前で公開する仮想 MIDI ソース **MIDITouchPad**。IAC Driver の設定は不要で、
DAW 側の MIDI 入力デバイス一覧にそのまま現れる。

## 数字キーでタッチ CC を切り替える

メニューの「数字キーでタッチ CC を切り替え」をオンにすると、**最後に押した数字キー**に応じて、
タッチ有無を送る CC 番号が変わる。DAW など他のアプリが前面にあるときでも効く。

| 押すキー | タッチ CC（基準 CC が 64 の場合） |
| --- | --- |
| `1` | CC 64 |
| `2` | CC 65 |
| `3` | CC 66 |
| … | … |
| `9` | CC 72 |
| `0` | CC 73 |

- 「基準 CC」（既定 64）に、`1`〜`9` なら 0〜8、`0` なら 9 を足した番号になる。127 を超える場合は 127 に丸める。
- テンキーの数字も同じように扱う。`⌘` を押しながらの入力は無視する。
- 指が触れたまま切り替えると、古い CC に 0、新しい CC に 127 を送る。押しっぱなしの CC は残らない。
- メニューの「送信中のタッチ CC」で、いま使っている CC 番号を確認できる。
- 初期状態はオフで、起動のたびに `1` 相当（基準 CC）に戻る。
- 他のアプリで数字を入力するたびに切り替わってしまうので、文章を打つときなどはオフにする。

### 入力監視の許可

他のアプリが前面のときにキーを拾うには、システム設定 → プライバシーとセキュリティ →
**入力監視** で MIDITouchPad を許可する必要がある。許可が無いと、メニューのパネルを開いて
いるときしか反応しない。

1. トグルをオンにすると許可ダイアログが出るので、「システム設定を開く」を選んで MIDITouchPad をオンにする。
2. パネルの表示が緑の「他のアプリが前面でも有効です」になれば有効。許可後に変わらなければ、アプリを一度終了して開き直す。
3. 一覧に MIDITouchPad が出ていない場合は、一覧の下の「＋」から `MIDITouchPad.app` を追加する。

### 許可しているのに緑にならないとき

以前に別の署名のビルド（ad-hoc 署名の自家ビルドなど）を許可していると、古い許可が残っていて、
今のアプリと一致せず無効扱いになることがある。古い許可を消してから、もう一度許可する。

```sh
tccutil reset ListenEvent local.miditouchpad
```

その後アプリを開き直して、トグルをオフ→オンにする。

## ビルドと起動

```sh
./build.sh
open build/MIDITouchPad.app
```

ここで作られるのは ad-hoc 署名のアプリで、自分の Mac で動かすだけなら十分。Developer ID で
署名する（Hardened Runtime 付き）には、証明書名を渡す。

```sh
SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" ./build.sh
```

起動すると Dock には出ず、メニューバーに手のアイコンが出て即座に送信を開始する。
アイコンをクリックすると現在の X/Y/タッチ状態と設定が見える。

アプリのアイコンは `tools/make_icon.swift` で描いている。作り直すときは
`swift tools/make_icon.swift .` を実行する。

## 仕組みと制約

- タッチ位置は非公開フレームワーク `MultitouchSupport` を `dlopen` して読んでいる。
  ヘッダが無いので `MTTouch` の構造体レイアウトに依存しており、OS 更新で壊れうる。
- 非公開フレームワークを使うため App Sandbox は有効にできず、App Store では配布できない。
  配布版は Developer ID で署名し、Apple の公証を受けている。
- 読み取りは受動的なので、トラックパッドは通常どおりカーソル操作にも使われる。
  MIDI 操作中にクリックやスワイプが誤爆する点は許容が必要。
- 複数の指が触れている場合は、最初に接触した 1 本だけを追跡する。
- 数字キーの全域監視には「入力監視」の許可が必要（上記参照）。
